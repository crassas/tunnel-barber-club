## Publicação na Vercel

A versão publicada usa `dist/` como raiz do site, `api/` para as funções e `server/` para a lógica do backend. Os ficheiros HTML, CSS e JS na raiz pertencem à versão anterior. Faz as alterações ao site publicado em `dist/`.

Executa `npm ci` e `npm test` antes de publicar. As credenciais e os endereços de associação dos barbeiros (`TUNNEL_RAFA_EMAIL` e `TUNNEL_BRUNO_EMAIL`) são configurados na Vercel.
